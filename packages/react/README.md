# @edu-sdk/react

React components for learning materials generated by [`edu-sdk`](../core/README.md).

Requires React 18 or later. Installing this package also pulls in `edu-sdk`.

## Install

```bash
pnpm add @edu-sdk/react
```

Import the default stylesheet once (typically in your root layout):

```tsx
import "@edu-sdk/react/styles.css";
```

## Quick start

Generate with `edu-sdk`, then pass the result into a component:

```tsx
import { createQuiz } from "edu-sdk";
import { Quiz } from "@edu-sdk/react";
import "@edu-sdk/react/styles.css";

const quiz = await createQuiz({
  model: "google/gemini-3.6-flash",
  content,
  count: 10,
  difficulty: "medium",
});

export function QuizDemo() {
  return (
    <Quiz
      questions={quiz.content}
      onComplete={(result) => {
        console.log(result.score, result.total);
      }}
    />
  );
}
```

## Components

| Component | Props | Source |
| --- | --- | --- |
| `Quiz` | `questions`, `onComplete?` | `createQuiz` / `gradeQuiz` |
| `Flashcards` | `flashcards` | `createFlashcards` |
| `StudyGuide` | `studyGuide` | `createStudyGuide` |
| `PracticeProblems` | `problems` | `createPracticeProblems` |
| `StudySession` | `session`, `allowSkip?`, `autoAdvance?`, `renderNotes?`, `onBlockComplete?`, `onSessionComplete?` | `createStudySession` |

There is no React component for `createNote` (Markdown only) or `createLearningSet`. Compose the material components from nested artifacts, or use `StudySession` / a custom runner for session agendas — see the docs site Guides.

### Examples

```tsx
import {
  Quiz,
  Flashcards,
  StudyGuide,
  PracticeProblems,
  StudySession,
} from "@edu-sdk/react";

<Quiz questions={quiz.content} />
<Flashcards flashcards={cards.content} />
<StudyGuide studyGuide={guide} />
<PracticeProblems problems={problems.content} />
<StudySession session={session.content} />
```

## Styling

Every component accepts `className` and a `classNames` object for targeting inner parts. Import `@edu-sdk/react/styles.css` once for the default look, then override with your own classes as needed.
