# @edu-sdk/react

React components for learning materials generated by [`edu-sdk`](../core/README.md).

Requires React 18 or later. Installing this package also pulls in `edu-sdk`.

## Install

```bash
pnpm add @edu-sdk/react
```

Import the default stylesheet once (typically in your root layout):

```tsx
import "@edu-sdk/react/styles.css";
```

## Quick start

Generate with `edu-sdk`, then pass the result into a component:

```tsx
import { createQuiz } from "edu-sdk";
import { Quiz } from "@edu-sdk/react";
import "@edu-sdk/react/styles.css";

const quiz = await createQuiz({
  model: "google/gemini-3.6-flash",
  content,
  count: 10,
  difficulty: "medium",
});

export function QuizDemo() {
  return (
    <Quiz
      questions={quiz.content}
      onComplete={(result) => {
        console.log(result.score, result.total);
      }}
    />
  );
}
```

`Quiz` takes `QuizQuestion[]` — each question needs a required `id` (generators stamp this). `onComplete` receives `GradeQuizResult`, which may include `byTopic` when questions have `topics`. The component does not render topics or `byTopic` yet — read them from `onComplete` if you need them.

Pass optional `learnerContext` at generation time in `edu-sdk` (see the [edu-sdk README](../core/README.md) personalization section).

## Components

| Component | Props | Source |
| --- | --- | --- |
| `Quiz` | `questions` (`QuizQuestion[]`), `onComplete?` | `createQuiz` / `gradeQuiz` |
| `Flashcards` | `flashcards` | `createFlashcards` |
| `StudyGuide` | `studyGuide` | `createStudyGuide` |
| `PracticeProblems` | `problems` | `createPracticeProblems` |
| `StudySession` | `session`, material `render*` / `*Props`, `allowSkip?`, `autoAdvance?`, `onBlockComplete?`, `onSessionComplete?` | `createStudySession` |

There is no React component for `createNote` (Markdown only) or `createLearningSet`. Compose the material components from nested artifacts, or use `StudySession` / a custom runner for session agendas — see the docs site Guides. `StudySession` can pass props through to nested materials (`quizProps`, …) or replace them (`renderQuiz`, …).

### Examples

```tsx
import {
  Quiz,
  Flashcards,
  StudyGuide,
  PracticeProblems,
  StudySession,
} from "@edu-sdk/react";

<Quiz questions={quiz.content} />
<Flashcards flashcards={cards.content} />
<StudyGuide studyGuide={guide} />
<PracticeProblems problems={problems.content} />
<StudySession session={session.content} />
```

## Styling

Every component accepts `className` and a `classNames` object for targeting inner parts. Import `@edu-sdk/react/styles.css` once for the default look, then override with your own classes as needed.
