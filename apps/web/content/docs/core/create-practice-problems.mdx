title: createPracticeProblems
description: Generate practice problems from educational content.
---

Generates practice problems from educational content. Each problem includes a hint, an answer, and a worked solution.

## Usage

```ts
import { createPracticeProblems } from "edu-sdk";

const problems = await createPracticeProblems({
  model: "google/gemini-3.6-flash",
  content,
  count: 5,
  difficulty: "medium"
});
```

## Options

| Option | Type | Required | Default |
| --- | --- | --- | --- |
| `model` | `string \| LanguageModel` | Yes | — |
| `content` | `string \| FileContent` | Yes | — |
| `count` | `number` (positive int) | Yes | — |
| `difficulty` | `"easy" \| "medium" \| "hard"` | No | `"medium"` |
| `learnerContext` | `LearnerContext` | No | — |

`content` may be a string or [`FileContent`](/docs/core/extract-content) (PDF / text / markdown bytes).

`learnerContext` is optional personalization input. See [Personalization](/docs/guides/personalization).

## Returns

`Promise<Artifact<PracticeProblem[]>>`

```ts
{
  id: string;
  title: string;
  description?: string;
  metadata: {
    createdAt: string;
    model: string;
    difficulty: "easy" | "medium" | "hard";
  };
  content: PracticeProblem[];
}
```

Each problem in `content` contains:

```ts
{
  id: string;
  question: string;
  hint: string;
  answer: string;
  solution: string;
  topics?: string[];
}
```

Generation produces **1–4** `topics` per problem. On the public `PracticeProblem` type, `topics` is optional so hand-authored sets can omit them.

## Example

```ts
import { createPracticeProblems } from "edu-sdk";

const problems = await createPracticeProblems({
  model: "google/gemini-3.6-flash",
  content: worksheetNotes,
  count: 6,
  difficulty: "hard"
});

// <PracticeProblems problems={problems.content} />
```

Render with [`<PracticeProblems />`](/docs/react/practice-problems).
