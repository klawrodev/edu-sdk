Generates a multiple-choice quiz from educational content.

## Usage

```ts
import { createQuiz } from "edu-sdk";

const quiz = await createQuiz({
  model: "google/gemini-3.6-flash",
  content,
  count: 10,
  difficulty: "hard",
  numOfOptions: 4
});
```

## Options

| Option | Type | Required | Default |
| --- | --- | --- | --- |
| `model` | `string \| LanguageModel` | Yes | — |
| `content` | `string \| FileContent` | Yes | — |
| `count` | `number` (positive int) | Yes | — |
| `difficulty` | `"easy" \| "medium" \| "hard"` | No | `"medium"` |
| `numOfOptions` | `number` (min 2) | No | `4` |
| `learnerContext` | `LearnerContext` | No | — |

`content` may be a string or [`FileContent`](/docs/core/extract-content) (PDF / text / markdown bytes).

`learnerContext` is optional personalization input. See [Personalization](/docs/guides/personalization).

## Returns

`Promise<Artifact<QuizQuestion[]>>`

```ts
{
  id: string;
  title: string;
  description?: string;
  metadata: {
    createdAt: string;
    model: string;
    difficulty: "easy" | "medium" | "hard";
  };
  content: QuizQuestion[];
}
```

Each question in `content` is a `QuizQuestion`:

```ts
{
  id: string;
  question: string;
  options: string[];
  correctAnswer: number;
  topics?: string[];
}
```

`correctAnswer` is zero-indexed. Artifact `id` / leaf `id`s and `metadata` are SDK-generated; `title` and optional `description` come from the model.

Generation always produces **1–4** `topics` tags per question. On the public `QuizQuestion` type, `topics` is optional so hand-authored quizzes (and grading) can omit them. `id` is always required.
