Generates flashcards from educational content.

## Usage

```ts
import { createFlashcards } from "edu-sdk";

const flashcards = await createFlashcards({
  model: "google/gemini-3.6-flash",
  content,
  count: 10,
  difficulty: "medium"
});
```

## Options

| Option | Type | Required | Default |
| --- | --- | --- | --- |
| `model` | `string \| LanguageModel` | Yes | — |
| `content` | `string \| FileContent` | Yes | — |
| `count` | `number` (positive int) | Yes | — |
| `difficulty` | `"easy" \| "medium" \| "hard"` | No | `"medium"` |
| `learnerContext` | `LearnerContext` | No | — |

`content` may be a string or [`FileContent`](/docs/core/extract-content) (PDF / text / markdown bytes).

`learnerContext` is optional personalization input. See [Personalization](/docs/guides/personalization).

## Returns

`Promise<Artifact<Flashcard[]>>`

```ts
{
  id: string;
  title: string;
  description?: string;
  metadata: {
    createdAt: string;
    model: string;
    difficulty: "easy" | "medium" | "hard";
  };
  content: Flashcard[];
}
```

Each flashcard in `content` contains:

```ts
{
  id: string;
  front: string;
  back: string;
  topics?: string[];
}
```

Generation produces **1–4** `topics` per card. On the public `Flashcard` type, `topics` is optional so hand-authored decks can omit them. `id` is always present on generated cards.

## Example

```ts
import { createFlashcards } from "edu-sdk";

const flashcards = await createFlashcards({
  model: "google/gemini-3.6-flash",
  content: notes,
  count: 8,
  difficulty: "easy"
});

// <Flashcards flashcards={flashcards.content} />
```

Render with [`<Flashcards />`](/docs/react/flashcards).
