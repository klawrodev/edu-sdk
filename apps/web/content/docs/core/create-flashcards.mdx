Generates flashcards from educational content.

## Usage

```ts
import { createFlashcards } from "edu-sdk";

const flashcards = await createFlashcards({
  model: "google/gemini-3.6-flash",
  content,
  count: 10,
  difficulty: "medium"
});
```

## Options

| Option | Type | Required | Default |
| --- | --- | --- | --- |
| `model` | `string \| LanguageModel` | Yes | — |
| `content` | `string` | Yes | — |
| `count` | `number` (positive int) | Yes | — |
| `difficulty` | `"easy" \| "medium" \| "hard"` | No | `"medium"` |

## Returns

`Promise<Artifact<Flashcard[]>>`

```ts
{
  id: string;
  title: string;
  description?: string;
  metadata: {
    createdAt: string;
    model: string;
    difficulty: "easy" | "medium" | "hard";
  };
  content: Flashcard[];
}
```

Each flashcard in `content` contains:

```ts
{
  id: string;
  front: string;
  back: string;
}
```

## Example

```ts
import { createFlashcards } from "edu-sdk";

const flashcards = await createFlashcards({
  model: "google/gemini-3.6-flash",
  content: notes,
  count: 8,
  difficulty: "easy"
});

// <Flashcards flashcards={flashcards.content} />
```
