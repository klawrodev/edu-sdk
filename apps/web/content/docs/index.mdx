Edu SDK is two packages that work together: generate learning materials with `edu-sdk`, then render them with `@edu-sdk/react`.

## Generate → UI

| Generation | UI |
| --- | --- |
| [`createFlashcards()`](/docs/core/create-flashcards) | [`<Flashcards />`](/docs/react/flashcards) |
| [`createQuiz()`](/docs/core/create-quiz) | [`<Quiz />`](/docs/react/quiz) |
| [`createStudyGuide()`](/docs/core/create-study-guide) | [`<StudyGuide />`](/docs/react/study-guide) |
| [`createPracticeProblems()`](/docs/core/create-practice-problems) | [`<PracticeProblems />`](/docs/react/practice-problems) |
| [`createNote()`](/docs/core/create-note) | — (Markdown string) |

## Also in core

| API | Role |
| --- | --- |
| [`extractContent()`](/docs/core/extract-content) | Extract text from PDF / text / markdown bytes |
| [`createLearningSet()`](/docs/core/create-learning-set) | Several material types from one call |
| [`createStudySession()`](/docs/core/create-study-session) | Timed agenda plus matching materials |
| [`gradeQuiz()`](/docs/core/grade-quiz) | Score submitted quiz answers (optional `byTopic`) |
| [Assessment](/docs/core/assessment) | `createQuizAttempt()` / `completeQuizAttempt()` lifecycle |
| `buildLearnerContext()` / `analyzePastWork()` | Personalization helpers — see [Personalization](/docs/guides/personalization) |
