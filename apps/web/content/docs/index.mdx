Edu SDK is two packages that work together:

<Cards>
  <Card title="edu-sdk" href="/docs/core">
    Generate learning materials from content with a language model.
  </Card>
  <Card title="@edu-sdk/react" href="/docs/react">
    Render that data as UI.
  </Card>
</Cards>

| Generation | UI |
| --- | --- |
| [`createFlashcards()`](/docs/core/create-flashcards) | [`<Flashcards />`](/docs/react/flashcards) |
| [`createQuiz()`](/docs/core/create-quiz) | [`<Quiz />`](/docs/react/quiz) |
| [`createStudyGuide()`](/docs/core/create-study-guide) | [`<StudyGuide />`](/docs/react/study-guide) |
| [`createPracticeProblems()`](/docs/core/create-practice-problems) | [`<PracticeProblems />`](/docs/react/practice-problems) |
| [`createNote()`](/docs/core/create-note) | — |

`createNote()` returns an `Artifact` whose `content` is Markdown. It has no React component.

## Also in core

Beyond the create → UI pairs above:

- [`createLearningSet()`](/docs/core/create-learning-set) — choose quiz, flashcards, practice problems, notes, and/or study guide in one call
- [`gradeQuiz()`](/docs/core/grade-quiz) — score submitted quiz answers
- [Assessment](/docs/core/assessment) — `createQuizAttempt()` / `completeQuizAttempt()` for attempt lifecycle

Start with [Installation](/docs/getting-started/installation), then [Quick Start](/docs/getting-started/quick-start) to generate a quiz and render it.
