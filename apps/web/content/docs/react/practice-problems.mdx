title: PracticeProblems
description: Render practice problems generated by createPracticeProblems.
---

Renders practice problems from [`createPracticeProblems()`](/docs/core/create-practice-problems). Students can reveal hint, answer, and solution.

## Usage

```tsx
import { PracticeProblems } from "@edu-sdk/react";
import "@edu-sdk/react/styles.css";

<PracticeProblems problems={problems.content} />
```

## Props

```ts
type PracticeProblemsProps = {
  problems: PracticeProblem[];
  className?: string;
  classNames?: PracticeProblemsClassNames;
};
```

## classNames

| Key | Part |
| --- | --- |
| `root` | Root container |
| `progress` | Problem index |
| `problem` | Current problem |
| `question` | Question text |
| `actions` | Reveal buttons |
| `hintButton` | Hint button |
| `answerButton` | Answer button |
| `solutionButton` | Solution button |
| `hint` | Hint panel |
| `answer` | Answer panel |
| `solution` | Solution panel |
| `controls` | Previous / next row |
| `previousButton` | Previous button |
| `nextButton` | Next button |

## Example

```tsx
<PracticeProblems
  problems={problems.content}
  className="my-problems"
  classNames={{
    question: "my-question",
    hint: "my-hint"
  }}
/>
```

See [Styling](/docs/react/styling) for `styles.css` and CSS variables.
