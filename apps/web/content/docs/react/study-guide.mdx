Renders a study guide from [`createStudyGuide()`](/docs/core/create-study-guide).

Unlike other components, pass the **full** `Artifact` (not `artifact.content`) so the component can render the title and sections.

## Usage

```tsx
import { StudyGuide } from "@edu-sdk/react";
import "@edu-sdk/react/styles.css";

<StudyGuide studyGuide={studyGuide} />
```

## Props

```ts
type StudyGuideProps = {
  studyGuide: Artifact<StudyGuideContent>;
  className?: string;
  classNames?: StudyGuideClassNames;
};
```

## classNames

| Key | Part |
| --- | --- |
| `root` | Root article |
| `title` | Title |
| `summary` | Summary text |
| `section` | Section wrapper |
| `sectionTitle` | Section heading |
| `keyConcepts` | Key concepts list |
| `keyConcept` | One concept card |
| `conceptName` | Concept name |
| `conceptExplanation` | Concept explanation |
| `reviewQuestions` | Review questions list |
| `reviewQuestion` | One review question |

## Example

```tsx
<StudyGuide
  studyGuide={studyGuide}
  className="my-guide"
  classNames={{
    title: "my-title",
    keyConcept: "my-concept"
  }}
/>
```

See [Styling](/docs/react/styling) for `styles.css` and CSS variables.
