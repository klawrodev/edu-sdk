title: Flashcards
description: Render flashcards generated by createFlashcards.
---

Renders a flip-through deck of flashcards from [`createFlashcards()`](/docs/core/create-flashcards).

## Usage

```tsx
import { Flashcards } from "@edu-sdk/react";
import "@edu-sdk/react/styles.css";

<Flashcards flashcards={flashcards.content} />
```

## Props

```ts
type FlashcardsProps = {
  flashcards: Flashcard[];
  className?: string;
  classNames?: FlashcardsClassNames;
};
```

## classNames

| Key | Part |
| --- | --- |
| `root` | Root container |
| `counter` | Card index |
| `card` | Flip card |
| `controls` | Previous / next row |
| `prevButton` | Previous button |
| `nextButton` | Next button |

## Example

```tsx
<Flashcards
  flashcards={flashcards.content}
  className="my-flashcards"
  classNames={{
    card: "my-card",
    nextButton: "my-next"
  }}
/>
```

See [Styling](/docs/react/styling) for `styles.css` and CSS variables.
